# Rooftop Dojo

Parallax v2 pack regenerated for the port runtime.

- Master source: `source/rooftop-dojo-base-imagegen-v2.png` and runtime alias `/stages/rooftop-dojo/rooftop-dojo.png`.
- Layers: `background-pack.json` declares far/mid/near depth and scroll. v2 layers keep provider pixels and apply only deterministic masks or attenuation.
- Direction: night combat dojo, charcoal/umber/slate, Baki-like anatomy, no neon, text, or logos.
- Validation: `validate_background_pack.py` writes `qa/background-composite.png` and `qa/background-scroll.gif` with representative `imagegen` provenance.
