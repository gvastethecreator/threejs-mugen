# Mara Cinta

Karateka de torneo con gi carbón, faja rojo óxido y cinta hueso. La regeneración v2 lleva hombros, antebrazos y core densos con anatomía de manga de combate tipo Baki, sin ropa chillona.

- Atlas: `sprite-sheet-alpha.png` + `manifest.json`
- Fuente: `source/mara-cinta-action-grid-imagegen.png` (Imagegen v2; también queda el original v2 con sufijo).
- QA: `qa/identity-consistency-report.json`, `qa/frame-alignment-report.json`,
  `qa/animation-contract-report.json`, `qa/motion-variation-report.json`
- MUGEN-lite: `mugen/mara.def`, `.cmd`, `.cns`, `.air` y `runtime-states.json` cubren el núcleo de juego.
- Pendiente: los gates de variación/contrato de animación siguen rojos por recomposición determinista de la grilla; además paletas secundarias, SFF binario nativo y colisiones por frame.
