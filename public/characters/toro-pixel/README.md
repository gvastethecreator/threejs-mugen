# Toro Pixel

Grappler pesado de anatomía extrema: gi índigo profundo, cinturón ocre apagado, nuca y torso macizos. La regeneración v2 aplica musculatura de manga de combate tipo Baki y paleta contenida.

- Atlas: `sprite-sheet-alpha.png` + `manifest.json`
- Fuente: `source/toro-pixel-action-grid-imagegen.png` (Imagegen v2; también queda el original v2 con sufijo).
- QA: `qa/identity-consistency-report.json`, `qa/frame-alignment-report.json`,
  `qa/animation-contract-report.json`, `qa/motion-variation-report.json`
- MUGEN-lite: `mugen/toro.def`, `.cmd`, `.cns`, `.air` y `runtime-states.json` cubren el núcleo de juego.
- Pendiente: los gates de variación/contrato de animación siguen rojos por recomposición determinista de la grilla; además paletas secundarias, SFF binario nativo y colisiones por frame.
