# Geometry ledger

## Shared invariants

- One dominant artifact per mode and task.
- Header height is earned by global product controls only; project facts do not become a permanent dashboard row.
- One visible primary action and one current blocker at a time.
- Context panels are selection-owned and dismissible on desktop; long content scrolls inside the lens.
- Console/log output is an explicit tool, never a permanent fourth zone.
- Long evidence and technical data own their scroll container; the document does not hide nested scroll traps.

## Desktop anchors

| Context | Dominant region | Secondary region | Optional region | Scroll owner |
| --- | --- | --- | --- | --- |
| Runtime Match | Live fight | Compact context lens | Runtime controls | Lens; scene stays fixed |
| Inspect | Intake or loaded character artifact | Compatibility detail | Source tree/timeline | Selected detail |
| Studio object work | Scene/object canvas | Contextual inspector | Source tree or trace timeline | Inspector/timeline |
| Studio evidence/build | Selected causal chain | Repair/proof detail | Live preview strip | Chain and detail independently |

## Narrow anchors

- 390 px design target with no horizontal document overflow.
- Artifact occupies the first meaningful viewport.
- Exactly one of tree, inspector, workflow, or log may be expanded below/over the artifact.
- Runtime controls use a compact bottom zone; Studio places the contextual sheet after the scene with preserved focus order.
- Primary actions stay reachable without traversing the full 2,700 px stacked desktop order.

## Proof sizes

- Desktop: 1440×1024.
- Narrow: 390×844.
- Long-data proof: inspector/evidence content exceeding one viewport.
- Costly-state proof: missing source, blocked build, source conflict/recovery, and runtime/WebGL failure where reproducible.
