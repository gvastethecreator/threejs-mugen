# Context card

- **Work unit:** `mugen-interface-redesign`
- **Primary archetype:** Creative studio/editor.
- **Bounded contexts:** Game runtime HUD, technical intake/inspector, diagnostic workbench.
- **User modes:** Act, create, diagnose.
- **Primary artifact:** The live playable fight, or the selected project object and the evidence that explains it.
- **Use pattern:** Repeated expert use under medium-to-high diagnostic pressure.
- **Input model:** Keyboard, mouse, gamepad, touch, local ZIP/folder.
- **Spatial model:** Adaptive workspace; Runtime earns a dedicated scene-first composition.
- **Truth boundary:** No fake compatibility, readiness, trace, build, or export success.
- **Costly states:** Missing/stale source, conflict/recovery, partial provenance, empty/failed trace, runtime busy/WebGL failure, blocked build, long data, narrow viewport.
- **Proof obligation:** All three public modes, all eight Studio views, desktop+narrow, blocked+recovery, and cross-view consistency on the same real project state.
