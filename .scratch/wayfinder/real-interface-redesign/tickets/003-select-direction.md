# Question

Which of the three generated interface directions should become the production target?

# Options

1. Fight First / Context Lens — `../concepts/01-fight-first-context-lens.png`
2. Evidence Split / Cause and Repair — `../concepts/02-evidence-split-cause-repair.png`
3. Scene Desk / Layered Workbench — `../concepts/03-scene-desk-layered-workbench.png`

# Answer

Cristian selected option 1, **Fight First / Context Lens**, on 2026-07-30.

# Why HITL

The options deliberately make incompatible hierarchy and interaction decisions. Choosing on the user's behalf would turn a product-direction decision into self-certification.

# Resolution

The visual target is `../concepts/01-fight-first-context-lens.png`. Runtime is the purest expression of the direction; Inspect and Studio must reuse the quiet global rail, dominant live artifact, and one task-owned contextual lens without forcing the fight scene into jobs where another artifact should dominate.
