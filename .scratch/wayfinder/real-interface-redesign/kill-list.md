# Kill list

The redesign must remove these structural defaults, not merely restyle them:

1. Permanent left pipeline + center stage + right dashboard + bottom console.
2. Cyber-terminal identity: tiny mono copy, pervasive uppercase, grids, amber stripes, and command-center chrome.
3. The same readiness/blocker truth repeated as score, badge, card, pipeline, overlay, and log.
4. Nested bordered cards and pill mosaics used as hierarchy.
5. The stage used as unrelated wallpaper or covered by a next-action banner.
6. A fashionable substitute such as faux brutalism, glass dashboards, glossy game HUDs, or ornamental 3D.
7. Decorative metrics, fake previews, or success claims without exact runtime/evidence provenance.
